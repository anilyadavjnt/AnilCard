# AnilCard — SwiftUI iOS App

AnilCard is a modern **digital profile/contact card iOS application** built using **SwiftUI**.

The app presents a clean personal profile with contact information and social links such as **GitHub** and other professional profiles.

## 📱 Features

* Modern SwiftUI UI
* Personal profile card
* Profile image
* Name and professional title
* GitHub profile link
* LinkedIn profile link
* Clean and responsive layout
* Simple and reusable SwiftUI components

## 🛠️ Technologies Used

* **Swift**
* **SwiftUI**
* **Xcode**
* **SF Symbols**
* **URL Handling**
* **Git & GitHub**

## 🚀 Getting Started

### Requirements

* macOS
* Xcode
* iOS Simulator or physical iPhone

### Installation

1. Clone the repository.

```bash
git clone https://github.com/anilyadavjnt/AnilCard-SwiftUI.git
```

2. Open the project in Xcode.

3. Select an iOS Simulator or connected iPhone.

4. Press **Run ▶**.
